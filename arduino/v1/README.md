# V1 — Protótipo Inicial

## Objetivo
Primeira automação local de irrigação para validar conceito da estufa inteligente.

## Hardware
- Arduino
- Sensor de umidade de solo simples
- DHT11
- Display OLED
- 1 bomba de água

## Características técnicas
- Controle totalmente local (sem rede/API).
- Loop simples de leitura e atuação.
- Exibição direta no display OLED.

## Limitações
- Sem histórico de dados.
- Sem acesso remoto.
- Lógica pouco modular para crescimento.

## Valor desta versão
A V1 é importante como base experimental: confirma leitura de sensores, acionamento de bomba e integração inicial entre módulos.
